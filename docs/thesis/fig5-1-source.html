AUTOMATIC

Discovered

  • robots rules honoured
  • ≤ 3 sitemaps
  • bounded pages per domain
  • 900 ms between requests
↓

Extracted

  • static parser preferred
  • browser ≤ 8 states, GET only
  • PDF ≤ 8 MB
  • never clicks submit
↓

Scored

  • fields mapped to fixed slots
  • bonus: official seed, explicit lost-property wording
  • penalty: login required
MODEL DECISION

Classified

  • the page is fetched again through the same request guard
  • scripts, event handlers and pre-filled values are stripped
  • the model returns a class, a confidence and a quote of the evidence it used
↓
EVERY CHECK MUST PASS

Deterministic checks

  • the quote exists in the page just fetched
  • the contact value appears inside that quote
  • the candidate has official provenance
  • the destination is on the same official site
  • the class is one the traveller opens themselves
OUTCOME

Accepted

  • audit record stored: policy version, model, source hash, quote hash, final URL
  • publication refuses an automated acceptance without one

Rejected

  • reason recorded and kept

Left for a person

  • any failed check returns the candidate to the queue
PUBLISHED

Published

  • public schema validated
  • byte length + SHA-256 per resource
  • versioned public feed
  • coverage may not fall without an explicit override

Only a person can grant

  • an assisted-fill adapter — 5 published, all fill-only
  • a submission adapter — none published
  • the model may grant neither, at any confidence

Three ways back into the queue

  • the page's stable content hash changes
  • ninety days pass since the decision
  • weekly verification finds a redirect, a dead URL or a changed form
A model decision reaches Published only through checks that do not involve the model.

The quote it relies on must still be present in the page the pipeline just fetched, and the contact must sit inside that quote. Assisted filling and submission stay outside this path entirely: a wrong contact detail costs part of a short recovery window, and a wrongly filled form costs the traveller their own statement.
